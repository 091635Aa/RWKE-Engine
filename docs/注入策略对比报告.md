## 3. 条纹问题（长会话重复模式）分析与治理

**诊断**：条纹 = ①跨轮句式复读（同一回复反复出现）②单字爆走（'花花花花'）。根因：静态偏置在长 State 反馈下形成 attractor + 基座模型未对话对齐。

**缓和注入变体（本报告实现）**：偏置 RMS 归一（强度有界 0.5λ，与质心范数漂移解耦）+ 单轮前强后弱衰减（PIS 进度调度）+ 回响池容量 32（质心跟随近期情绪）。

## 6. 情感能力增幅结论（对照 70%/300%/400% 目标）

- [0.4B] S1_基线_裸：情感增幅 **0.0%** —
- [0.4B] S2_现行注入：情感增幅 **-89.4%** —
- [0.4B] S3_缓和_未达标：情感增幅 **-16.6%** —
- [1.5B] S1_基线_裸：情感增幅 **0.0%** —
- [1.5B] S2_现行注入：情感增幅 **381.3%** ✅ ≥70%
- [1.5B] S3_缓和注入：情感增幅 **-14.2%** —

> **数据可信度注记**：1.5B S2（现行注入）的 +381% **不可作为能力证据**——其 20~30 轮后退化为英文词循环（'interface of interface…'，条纹率 0.47），高密度数值部分来自退化文本的统计噪声。1.5B 上**可信的**情感增幅实测来自连续对话实验（挂日记+注入 vs 裸，可读内容对比）：情感词密度 0.207 vs 0.062/千字 = **+234%**，超过 70% 目标线。

> 300%/400% 目标在 World 基座 + 100 轮长会话场景未以可信方式达成——该场景主导因素是基座模型复读边界而非注入强度；换用对话对齐模型（RWKV7-G1）是释放该量级的正道。

## 7. 长文本稳定性

- 软重锚：会话 token 超 3072 自动回锚日记 State/零态（防越 ctx4096 训练窗）——100 轮全程触发且无越界退化
- 回响池容量上限（32）：质心跟随近期情绪，防长会话质心僵化
- eos 保护 + 开场 eos 禁步 + 会话级惩罚 + 连续重复压制：单字爆走与空回复清零（有效回复率 100%）
- 已知残留：句式复读（20~30 轮后），属基座模型边界

## 8. 策略推荐

1. **首选：缓和注入（S3）**——偏置归一+衰减+池容量 32：条纹率与裸基线持平（0.4B：0.400→0.019），情感方向保留，长会话不劣化。
2. **模型升级路径**：RWKV-8（ROSA/DeepEmbed）已发布、RWKV7-G1 为 World 的对话对齐升级版（支持思考模式，Ollama/GGUF 可用）——换用 G1 预期同时消除句式复读并放大情感增幅，框架零改动兼容。
3. **不建议**：在 World 基座上追求 λ 爬坡拉高情感指数——λ≥0.2 即触发 attractor（爬坡实验三档结果一致）。
4. 关于'无限研究模式/300% 自动停止'：已实现**有界**自动标定（达标即停、上限 3 档），未达标时如实报告并给出根因；无限循环与无限 token 代理在物理上不可行，以有界机制替代。
## 9. 探索增补：对话对齐模型 RWKV7-G1-1.5B 实测（缓和注入配置，100轮×3模式）

| 模式 | World-1.5B（基座） | G1-1.5B（对话对齐） | 说明 |
|---|---|---|---|
| A 裸 | 47.2 | **64.9** | 对话对齐使裸模型提升 +17.6 分（句式多样性显著更好） |
| B 注入 | 55.0（缓和后） | 41.8 | G1 上注入仍会在 ~11 轮后形成模板循环 |
| C 挂日记+注入 | 53.7（记忆 1/3） | 50.8（记忆 1/3，循环内容角色相关） | 复读内容含"画画"等锚点主题，质上更贴角色 |

**探索结论**：
1. 对话对齐（G1）对裸模型收益最大（47.2→64.9）；注入 attractor 是结构性问题，对齐模型上依然存在，故**推荐配置 = G1 裸模型 + RWKE 的 State 记忆框架，注入强度收敛到极低或按需触发**。
2. 日记 State 框架跨模型零改动迁移成功（G1 日记 State 生成+挂载+记忆命中 1/3 一路复用）。
3. G1 复读内容角色一致（"🎨✨画画是件很治愈的事"——锚点主题），质上优于 World 的机械循环。
4. 后续路径：RWKV-8（ROSA/DeepEmbed）+ 注入强度自适应触发（仅低情感轮注入，参考 P6 EDD 的 OQC 在线纠正思路）。
